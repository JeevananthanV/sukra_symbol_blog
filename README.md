## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/JeevananthanV/sukra_symbol_blog.git
cd sukra_symbol_blog
```

### Installation & Run

```bash
npm install
npm run dev
```

Open `http://localhost:5173` to view the platform.
