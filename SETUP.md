# Sukra Symbol Blog — Setup Guide

Welcome to the **Sukra Symbol Blog & Sacred Mudras Portal** setup guide. Built with React 18 and Vite.

- **GitHub Repository**: [https://github.com/JeevananthanV/sukra_symbol_blog](https://github.com/JeevananthanV/sukra_symbol_blog)
- **Author**: Jeevananthan V

---

## 📋 System Prerequisites

- **Node.js**: v18.0.0 or higher
- **npm**: v9.0.0 or higher
- **Git**: v2.30.0 or higher

---

## 📥 1. Clone the Repository

```bash
git clone https://github.com/JeevananthanV/sukra_symbol_blog.git
cd sukra_symbol_blog
```

---

## 📦 2. Install Dependencies & Run Locally

```bash
npm install
npm run dev
```

Open `http://localhost:5173` in your browser.

---

## 🏗️ 3. Production Build

```bash
npm run build
npm run preview
```
Output files will be generated in `dist/`.
